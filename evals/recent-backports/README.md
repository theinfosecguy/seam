# Recent backport case studies

The [24 October 2026 supplement](2026-10-24/README.md) records four recently
published fixes across Django, PydanticAI and LiteLLM, including unsuccessful
attempts and vendor comparisons. Read the [results](../../docs/recent-backports.md)
for the findings and coverage limits.

This evidence supplement is separate from the eight-case Python reference dataset
in [`evals/python`](../python/README.md). Its records are publication derivatives
of historical executions, not entries in the `seam eval` catalogue.
